Technical Composition

Collaborated with artists to transform chunked assets into gameplay-ready environments. Responsible for modular world-building, ensuring aesthetic consistency and optimal system performance across all game biomes.

Asset Pipeline & Optimization

Streamlined the production pipeline using TinyPNG for asset compression and Unity's internal texture management, resulting in high visual fidelity with a minimal VRAM and storage footprint.

Sprite Performance Architecture

Maximized GPU efficiency by using the Unity Sprite Editor to manually map vertices around 2D PNG assets. This precision "tracing" eliminates transparency overhead, cutting Overdraw to zero for a locked, high-performance frame rate.
