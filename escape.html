Escape: Unity to UE5

A psychological horror environment study. This project involved migrating a puzzle-based interior from Unity to Unreal Engine 5 to leverage Lumen's real-time GI.

Reconstruction • Horror Design • UE5 Migration

The Migration

The core of this project was a technical "re-lighting" exercise. Moving the scene to UE5 allowed for a more oppressive atmosphere, using high-contrast shadows and volumetric lighting to guide the player's eye toward puzzles.

Workflow Jump

Successfully translated Unity's lightmaps into Unreal's dynamic Lumen system, significantly improving the visual mood.

Level Design

Focused on claustrophobic set dressing and "quiet" storytelling through environmental details.
