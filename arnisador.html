Systems Programming

Architected the core combat logic using C#. I implemented a state-based system to manage player inputs, hitbox timing, and collision detection for precise martial arts strikes.

Animation Architecture

Leveraged Unity Blend Trees to create fluid movement transitions. By mapping input magnitude to animation parameters, I achieved smooth blending between movement and combat stances.

Character Pipeline

Explored the end-to-end technical art pipeline by performing rigging and skinning on 3D character models, ensuring mesh integrity during complex combat animations.
